# Screenshots

The README expects a dashboard screenshot at:

```
docs/screenshot.png
```

To add it:

1. Start the stack (API, simulator, Angular) and sign in at <http://localhost:4200>.
2. Capture the dashboard — a 1400×900 window works well, and a light theme matches the app.
3. Save it as `docs/screenshot.png` (PNG, ideally under 500 KB).
4. Commit it; the README image and this folder are already wired up.

Optional extras you can add later: `docs/devices.png` for the inventory and `docs/device-detail.png` for the map and shared-session panel.
